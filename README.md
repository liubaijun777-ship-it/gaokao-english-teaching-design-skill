# 高中英语教学设计 Claude Skill

A Claude Code skill for high school English lesson design in China, distilled from 33 research articles by **Tang Bangshun (唐邦顺)**, an English teaching researcher from Guangming District, Shenzhen, and author of the WeChat public account *邦邦英语单词*.

## What This Skill Contains

A practical teaching design framework covering:

- **Core Philosophy** — Discourse-based teaching; simultaneous development of language ability AND thinking quality (既得"语"又得"意")
- **Backward Design (逆向设计)** — Begin with the end in mind: authentic output task first, then scaffold backwards
- **Teaching-Learning-Assessment Alignment (教学评一致性)** — What is taught = what is learned = what is assessed
- **Text Interpretation (文本解读)** — 3-level deep reading: language → discourse structure → thematic meaning
- **Discourse Patterns** — PSR, Compare & Contrast, Assumption→Reality, Biography Arc, Review Structure
- **Scaffolding Framework** — 4-dimension model: Motivation / Content / Structure / Language
- **SOLO Theory Application** — 5 cognitive levels in question chain design
- **Teaching-Exam Alignment (教考衔接)** — Infusing gaokao reading logic into daily classroom instruction
- **AI-Assisted Lesson Design** — Prompts and tools for text analysis, reading question design, backward lesson planning
- **Lesson Type Playbooks** — Narrative (写人), Argumentative (议论), Reading-to-Writing (读写整合), Vocabulary Review
- **Diagnostic Table** — Common problems and root-cause fixes

## How to Install

1. Clone or download this repo
2. Copy `SKILL.md` into your Claude Code skills directory:
   ```bash
   mkdir -p ~/.claude/skills/教学设计
   cp SKILL.md ~/.claude/skills/教学设计/SKILL.md
   ```
3. Reload Claude Code — the skill appears as `/教学设计`

## Usage

Type `/教学设计` in Claude Code, followed by your request. Examples:

- `/教学设计 帮我设计外研版B5U2 Silent Spring 阅读课，逆向设计`
- `/教学设计 我有一篇记叙文写人课文，帮我设计问题链`
- `/教学设计 诊断这节课：学生读后续写写不出来`

## Source
